# Ashish Sharma | Personal Portfolio

Welcome to my personal portfolio website! This project showcases my skills, experience, and projects as a Backend Developer specializing in Python and Django. The website features a modern, responsive design with a glassmorphism UI, smooth animations, and a fully functional light/dark mode toggle.

## 🚀 Live Demo
Simply open `index.html` in your browser to view the portfolio locally.

## ✨ Features
* **Modern UI/UX**: Clean, attractive design utilizing glassmorphism effects and soft gradients.
* **Light & Dark Mode**: A seamless, fully integrated theme toggle that remembers your preference using local storage.
* **Responsive Design**: Fully optimized for desktops, tablets, and mobile devices.
* **Interactive Animations**: Dynamic text typing effects and scroll-reveal animations as you browse through the sections.
* **Sections Included**: 
  * Home (Hero section with typed text)
  * About Me (Personal details and experience)
  * Skills (Progress bars and technology cards)
  * Achievements (Animated statistics counters)
  * Portfolio (Showcase of recent projects)
  * Contact (Functional UI for reaching out)

## 🛠️ Technologies Used
* **Frontend**: HTML5, CSS3, Vanilla JavaScript
* **Styling**: Custom CSS with variables for theming, Flexbox/Grid for layout
* **Icons**: [Remix Icon](https://remixicon.com/) & [Devicon](https://devicon.dev/)
* **Animations**: 
  * [Typed.js](https://github.com/mattboldt/typed.js/) (Dynamic typing effect)
  * [ScrollReveal](https://scrollrevealjs.org/) (Scroll animations)
* **Fonts**: [Google Fonts - Poppins](https://fonts.google.com/specimen/Poppins)
